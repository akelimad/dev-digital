La gestion des exceptions en MySQL

Comment éviter qu'une procédure s'arrête brutalement à la première erreur.

1. Définition et rôle

Une exception est une erreur qui survient pendant l'exécution d'une instruction SQL (doublon de clé, valeur NULL interdite, table inexistante, aucune ligne trouvée...).

Sans gestion, MySQL arrête la procédure et affiche un message d'erreur technique. Avec un handler (gestionnaire d'erreur), on décide nous-mêmes quoi faire :

  • afficher un message clair à l'utilisateur ;
  • continuer ou arrêter proprement la procédure ;
  • annuler une transaction en cours (ROLLBACK).

Les handlers s'utilisent dans les procédures, les fonctions et les déclencheurs, à l'intérieur d'un bloc BEGIN ... END.

2. Syntaxe du handler

DECLARE type_handler HANDLER FOR condition [, condition ...]
    instruction;

Le DECLARE ... HANDLER se place au début du bloc, après les variables.

Les deux types de handler

TypeComportement
CONTINUEExécute l'instruction du handler, puis poursuit la procédure à l'instruction suivante.
EXITExécute l'instruction du handler, puis quitte le bloc BEGIN ... END courant.

Les conditions les plus utilisées

ConditionSignification
un code MySQL (ex. 1062)Une erreur précise : 1062 = doublon de clé, 1048 = valeur NULL interdite, 1146 = table inexistante.
SQLSTATE 'xxxxx'Un groupe d'erreurs. Ex. '23000' = violation de contrainte (doublon, NULL, clé étrangère).
SQLWARNINGTous les avertissements (SQLSTATE commençant par 01).
NOT FOUNDAucune ligne trouvée (SQLSTATE commençant par 02) : SELECT ... INTO sans résultat, fin d'un curseur.

Attention : dans certains supports, le code 1040 est cité pour « NULL interdit ». Le bon code est 1048 (le 1040 correspond à « trop de connexions »).

3. Handler EXIT

Exemple 1 : valeur NULL interdite (code 1048)

On ajoute un développeur sans nom alors que nomdev est NOT NULL.

DELIMITER //
CREATE PROCEDURE ps_ajouter_developpeur(
    IN p_num INT, IN p_nom VARCHAR(50), IN p_adr VARCHAR(100))
BEGIN
    DECLARE EXIT HANDLER FOR 1048
    BEGIN
        SELECT 'Erreur : le nom du développeur est obligatoire' AS message;
    END;

    INSERT INTO developpeur (numdev, nomdev, adrdev)
    VALUES (p_num, p_nom, p_adr);

    SELECT 'Développeur ajouté avec succès' AS message;
END //
DELIMITER ;

CALL ps_ajouter_developpeur(50, NULL, 'Rabat');

Résultat : le message d'erreur est affiché et la procédure s'arrête (le message « ajouté avec succès » n'apparaît pas).

Exemple 2 : aucune ligne trouvée (NOT FOUND)

DELIMITER //
CREATE PROCEDURE ps_chercher_developpeur(IN p_num INT)
BEGIN
    DECLARE v_nom VARCHAR(50);
    DECLARE EXIT HANDLER FOR NOT FOUND
        SELECT CONCAT('Aucun développeur avec le numéro ', p_num) AS message;

    SELECT nomdev INTO v_nom FROM developpeur WHERE numdev = p_num;

    SELECT CONCAT('Développeur trouvé : ', v_nom) AS message;
END //
DELIMITER ;

CALL ps_chercher_developpeur(999);

Attention : si le SELECT ... INTO retourne plusieurs lignes, ce n'est pas un NOT FOUND : MySQL déclenche l'erreur 1172 (Result consisted of more than one row), à gérer avec SQLEXCEPTION ou 1172.

Exemple 3 : une erreur quelconque (SQLEXCEPTION)

DELIMITER //
CREATE PROCEDURE ps_test_erreur()
BEGIN
    DECLARE EXIT HANDLER FOR SQLEXCEPTION
        SELECT 'Une erreur est survenue' AS message;

    INSERT INTO table_inexistante VALUES (1);
    SET @x = 99;
END //
DELIMITER ;

CALL ps_test_erreur();
SELECT @x;

Le handler s'est déclenché et la procédure s'est arrêtée : @x n'a pas été modifiée (NULL).

MySQL ne permet pas toujours de récupérer le code et le message exacts de l'erreur dans un handler SQLEXCEPTION. Si on en a besoin, on utilise GET DIAGNOSTICS, ou on prévoit un handler par erreur connue.

4. Handler CONTINUE

Avec CONTINUE, la procédure ne s'arrête pas : après le handler, elle reprend à l'instruction suivante.

DELIMITER //
CREATE PROCEDURE ps_doublon_continue()
BEGIN
    DECLARE CONTINUE HANDLER FOR SQLSTATE '23000'
        SET @erreur = 1;

    SET @erreur = 0;
    SET @etape = 1;
    INSERT INTO developpeur (numdev, nomdev) VALUES (1, 'Test');
    SET @etape = 2;
    INSERT INTO developpeur (numdev, nomdev) VALUES (1, 'Test');
    SET @etape = 3;
END //
DELIMITER ;

CALL ps_doublon_continue();
SELECT @etape, @erreur;

Résultat : @etape = 3 et @erreur = 1. Le 2e INSERT a provoqué un doublon de clé, le handler a noté l'erreur, et la procédure est allée jusqu'au bout.

Comment choisir ? EXIT quand la suite n'a plus de sens après l'erreur (on arrête). CONTINUE quand l'erreur est tolérable et que le reste du travail doit s'exécuter.

5. Utiliser un drapeau (variable indicatrice)

Technique très courante avec CONTINUE : le handler lève un drapeau, et on teste ce drapeau après l'instruction à risque.

DELIMITER //
CREATE PROCEDURE ps_ajouter_dev_flag(IN p_num INT, IN p_nom VARCHAR(50))
BEGIN
    DECLARE doublon BOOLEAN DEFAULT FALSE;
    DECLARE CONTINUE HANDLER FOR 1062 SET doublon = TRUE;

    INSERT INTO developpeur (numdev, nomdev) VALUES (p_num, p_nom);

    IF doublon THEN
        SELECT CONCAT('Le numéro ', p_num, ' existe déjà') AS message;
    ELSE
        SELECT 'Développeur ajouté' AS message;
    END IF;
END //
DELIMITER ;

6. Donner un nom à une erreur (DECLARE CONDITION)

Pour rendre le code plus lisible, on peut nommer une erreur, puis utiliser ce nom dans le handler.

DECLARE nom_condition CONDITION FOR
    { SQLSTATE 'valeur' | code_erreur_mysql };
DELIMITER //
CREATE PROCEDURE ps_ajouter_projet(IN p_num INT, IN p_titre VARCHAR(100))
BEGIN
    DECLARE projet_existe CONDITION FOR 1062;
    DECLARE EXIT HANDLER FOR projet_existe
        SELECT 'Ce numéro de projet existe déjà' AS message;

    INSERT INTO projet (numproj, titreproj) VALUES (p_num, p_titre);
    SELECT 'Projet ajouté' AS message;
END //
DELIMITER ;

7. Déclencher sa propre erreur : SIGNAL

Parfois, ce n'est pas MySQL qui détecte l'erreur, mais notre règle métier (ex. un projet doit exister). Avec SIGNAL, on lève nous-mêmes une exception avec un message personnalisé.

SIGNAL SQLSTATE 'valeur'
    SET MESSAGE_TEXT = 'votre message';

Pour les erreurs personnalisées, on utilise la valeur '45000' (« exception définie par l'utilisateur »).

Exemple : affecter un développeur à un projet

DELIMITER //
CREATE PROCEDURE ps_affecter_developpeur(IN p_numproj INT, IN p_numdev INT)
BEGIN
    DECLARE v_nb INT;

    SELECT COUNT(*) INTO v_nb FROM projet WHERE numproj = p_numproj;
    IF v_nb = 0 THEN
        SIGNAL SQLSTATE '45000'
            SET MESSAGE_TEXT = 'Projet introuvable';
    END IF;

    SELECT COUNT(*) INTO v_nb FROM developpeur WHERE numdev = p_numdev;
    IF v_nb = 0 THEN
        SIGNAL SQLSTATE '45000'
            SET MESSAGE_TEXT = 'Développeur introuvable';
    END IF;

    INSERT INTO realisation (numproj, numdev) VALUES (p_numproj, p_numdev);
END //
DELIMITER ;

CALL ps_affecter_developpeur(1, 9999);

Résultat : ERROR 1644 (45000): Développeur introuvable. La procédure s'arrête et l'appelant reçoit notre message.

8. Relancer une erreur : RESIGNAL

RESIGNAL fonctionne comme SIGNAL, mais s'utilise uniquement dans un handler : on intercepte une erreur, puis on la relance (souvent avec un message plus clair).

DELIMITER //
CREATE PROCEDURE ps_diviser(
    IN p_a INT, IN p_b INT, OUT p_resultat DOUBLE)
BEGIN
    DECLARE division_par_zero CONDITION FOR SQLSTATE '22012';
    DECLARE CONTINUE HANDLER FOR division_par_zero
        RESIGNAL SET MESSAGE_TEXT = 'Division par zéro : le dénominateur doit être différent de 0';

    IF p_b = 0 THEN
        SIGNAL division_par_zero;
    ELSE
        SET p_resultat = p_a / p_b;
    END IF;
END //
DELIMITER ;

CALL ps_diviser(10, 0, @r);
InstructionOù l'utiliser ?
SIGNALPartout dans la procédure.
RESIGNALUniquement dans un handler (sinon erreur « RESIGNAL when handler not active »).

9. Méthodologie

  1. Repérer l'instruction qui peut échouer (INSERT, SELECT INTO, appel d'une autre procédure...).
  2. Identifier l'erreur possible (code MySQL, SQLSTATE, NOT FOUND, SQLEXCEPTION).
  3. Choisir EXIT (on arrête) ou CONTINUE (on poursuit).
  4. Déclarer le handler au début du bloc, après les variables.
  5. Pour une règle métier non vérifiée par MySQL : tester avec IF puis SIGNAL.

10. TP sur la base Glogiciels

  3. Écrire ps_afficher_projet(p_numproj) qui affiche le titre du projet, ou « Projet introuvable » grâce à NOT FOUND.
