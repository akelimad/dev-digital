Les structures de contrôle en MySQL

IF · CASE · WHILE · REPEAT · LOOP — M203 Gestion de données

1. Définition

Une structure de contrôle permet de décider quelles instructions exécuter (condition) ou de répéter des instructions (boucle), au lieu de les exécuter simplement l'une après l'autre.

  • Structures conditionnelles : IF, CASE
  • Structures répétitives (boucles) : WHILE, REPEAT, LOOP
Les structures de contrôle s'utilisent à l'intérieur d'un programme stocké (procédure, fonction, trigger, événement), entre BEGIN et END. On ne peut pas écrire un IF ... END IF directement dans une requête seule.

2. Pourquoi les utiliser ? (utilité)

  • Faire des choix selon les données (prix, dates, valeurs saisies).
  • Répéter un calcul sans recopier le code.
  • Rendre une procédure ou une fonction intelligente : elle réagit au lieu d'exécuter toujours la même chose.
  • Contrôler les valeurs avant de modifier la base.

3. Cas d'utilisation

BesoinStructure
Classer un logiciel (économique / moyen / cher)IF ... ELSEIF ... ELSE
Donner l'état d'un projet (terminé, en cours...)CASE
Répéter tant qu'une condition est vraieWHILE

Les exemples de cette page utilisent la base Glogiciels : developpeur, projet, logiciel, realisation.

4. Syntaxe et exemples

4.1 IF — ELSEIF — ELSE

IF condition1 THEN
    instructions;
ELSEIF condition2 THEN
    instructions;
ELSE
    instructions;
END IF;

Exemple : classer un logiciel selon son prix.

DELIMITER //
CREATE PROCEDURE categorie_logiciel(IN p_codlog INT)
BEGIN
    DECLARE v_prix DECIMAL(10,2);

    SELECT prixlog INTO v_prix
    FROM logiciel
    WHERE codlog = p_codlog;

    IF v_prix >= 1000 THEN
        SELECT 'Logiciel cher' AS categorie;
    ELSEIF v_prix >= 300 THEN
        SELECT 'Logiciel moyen' AS categorie;
    ELSE
        SELECT 'Logiciel économique' AS categorie;
    END IF;
END //
DELIMITER ;

CALL categorie_logiciel(1);
Attention à l'écriture : ELSEIF en un seul mot, et chaque IF se termine par END IF;.

4.2 CASE (2 formes)

CASE existe sous deux formes : avec paramètre (on compare une valeur) et sans paramètre (on écrit des conditions complètes).

Forme 1 : CASE avec paramètre (on compare une expression à des valeurs, uniquement par égalité =)

CASE expression
    WHEN valeur1 THEN instructions;
    WHEN valeur2 THEN instructions;
    ELSE instructions;
END CASE;

Exemple : afficher le trimestre de début d'un projet.

DELIMITER //
CREATE PROCEDURE trimestre_projet(IN p_numproj INT)
BEGIN
    DECLARE v_deb DATE;

    SELECT datedeb INTO v_deb
    FROM projet
    WHERE numproj = p_numproj;

    CASE QUARTER(v_deb)
        WHEN 1 THEN SELECT 'Trimestre 1 (janv. - mars)' AS trimestre;
        WHEN 2 THEN SELECT 'Trimestre 2 (avr. - juin)'  AS trimestre;
        WHEN 3 THEN SELECT 'Trimestre 3 (juil. - sept.)' AS trimestre;
        WHEN 4 THEN SELECT 'Trimestre 4 (oct. - déc.)'  AS trimestre;
        ELSE SELECT 'Date de début inconnue' AS trimestre;
    END CASE;
END //
DELIMITER ;
Ici QUARTER(v_deb) est évalué une seule fois, puis comparé à 1, 2, 3, 4.

Forme 2 : CASE sans paramètre (chaque WHEN contient sa propre condition : <, >=, IS NULL, AND...)

CASE
    WHEN condition1 THEN instructions;
    WHEN condition2 THEN instructions;
    ELSE instructions;
END CASE;

Exemple : donner l'état d'un projet selon sa date de fin.

DELIMITER //
CREATE PROCEDURE statut_projet(IN p_numproj INT)
BEGIN
    DECLARE v_fin DATE;

    SELECT datefin INTO v_fin
    FROM projet
    WHERE numproj = p_numproj;

    CASE
        WHEN v_fin IS NULL THEN
            SELECT 'Date de fin non définie' AS statut;
        WHEN v_fin < CURDATE() THEN
            SELECT 'Terminé' AS statut;
        ELSE
            SELECT 'En cours' AS statut;
    END CASE;
END //
DELIMITER ;

CALL statut_projet(1);
CASE avec paramètreCASE sans paramètre
SyntaxeCASE expr WHEN valeurCASE WHEN condition
Comparaisonégalité seulement (=)toute condition (<, >=, AND, IS NULL...)
Quand l'utiliservaleurs précises (1, 2, 3 ou 'A', 'B')intervalles et conditions variées
Piège avec NULL : dans la forme avec paramètre, WHEN NULL ne correspond jamais (car NULL = NULL n'est pas vrai). Pour tester NULL, utilisez la forme sans paramètre avec IS NULL.
Dans une procédure, si aucune branche WHEN ne correspond et qu'il n'y a pas de ELSE, MySQL génère une erreur. Prévoyez toujours un ELSE.

4.3 WHILE (tester d'abord)

WHILE condition DO
    instructions;
END WHILE;

Exemple : augmenter le prix de 10 % tant qu'il est inférieur à 500.

DELIMITER //
CREATE PROCEDURE augmenter_prix(IN p_codlog INT)
BEGIN
    DECLARE v_prix DECIMAL(10,2);

    SELECT prixlog INTO v_prix
    FROM logiciel
    WHERE codlog = p_codlog;

    WHILE v_prix > 0 AND v_prix < 500 DO
        SET v_prix = v_prix * 1.10;
    END WHILE;

    UPDATE logiciel SET prixlog = v_prix WHERE codlog = p_codlog;
    SELECT v_prix AS nouveau_prix;
END //
DELIMITER ;
Boucle infinie : la condition doit pouvoir devenir fausse. Ici, si le prix valait 0, 0 * 1.10 resterait 0 pour toujours : d'où le test v_prix > 0.

4.4 REPEAT (exécuter d'abord, tester ensuite)

REPEAT
    instructions;
UNTIL condition
END REPEAT;

La boucle s'arrête quand la condition devient vraie (le contraire de WHILE). Elle s'exécute au moins une fois.

Exemple : prix d'un logiciel après 3 années d'augmentation de 5 %.

DELIMITER //
CREATE PROCEDURE prix_dans_3_ans(IN p_codlog INT)
BEGIN
    DECLARE v_prix DECIMAL(10,2);
    DECLARE v_annee INT DEFAULT 0;

    SELECT prixlog INTO v_prix
    FROM logiciel
    WHERE codlog = p_codlog;

    REPEAT
        SET v_prix  = v_prix * 1.05;
        SET v_annee = v_annee + 1;
    UNTIL v_annee >= 3
    END REPEAT;

    SELECT v_prix AS prix_apres_3_ans;
END //
DELIMITER ;

4.5 LOOP, LEAVE et ITERATE

etiquette: LOOP
    instructions;
    IF condition_arret THEN
        LEAVE etiquette;     -- sortir de la boucle
    END IF;
END LOOP etiquette;
  • LOOP ne s'arrête jamais toute seule : il faut obligatoirement un LEAVE.
  • LEAVE etiquette : sort de la boucle.
  • ITERATE etiquette : passe directement à l'itération suivante (comme continue).

Exemple : nombre d'années nécessaires pour qu'un logiciel dépasse 1000.

DELIMITER //
CREATE PROCEDURE annees_pour_1000(IN p_codlog INT)
BEGIN
    DECLARE v_prix DECIMAL(10,2);
    DECLARE v_annees INT DEFAULT 0;

    SELECT prixlog INTO v_prix
    FROM logiciel
    WHERE codlog = p_codlog;

    IF v_prix <= 0 THEN
        SELECT 'Prix invalide' AS message;
    ELSE
        boucle: LOOP
            IF v_prix >= 1000 THEN
                LEAVE boucle;
            END IF;
            SET v_prix   = v_prix * 1.10;
            SET v_annees = v_annees + 1;
        END LOOP boucle;

        SELECT v_annees AS nombre_annees;
    END IF;
END //
DELIMITER ;

4.6 Bonus : IF() et CASE dans une requête SELECT

Dans un SELECT (hors programme stocké), on utilise la fonction IF() et l'expression CASE ... END :

SELECT nomlog, prixlog,
       IF(prixlog >= 1000, 'Cher', 'Abordable') AS niveau,
       CASE
           WHEN prixlog >= 1000 THEN 'Cher'
           WHEN prixlog >= 300  THEN 'Moyen'
           ELSE 'Économique'
       END AS categorie
FROM logiciel;

-- CASE avec paramètre dans un SELECT
SELECT titreproj,
       CASE QUARTER(datedeb)
           WHEN 1 THEN 'T1'
           WHEN 2 THEN 'T2'
           WHEN 3 THEN 'T3'
           ELSE 'T4'
       END AS trimestre
FROM projet;
Différence : dans une requête, CASE ... END (sans CASE final) ; dans une procédure, CASE ... END CASE;.

5. Choisir la bonne structure

SituationChoix
Une ou deux conditions simplesIF
Plusieurs cas possibles, lisibilitéCASE
Nombre de répétitions inconnu, tester avantWHILE
Il faut exécuter au moins une foisREPEAT
Sortie au milieu de la boucleLOOP + LEAVE

6. Méthodologie simple

  1. Écrire le problème en français : « si..., alors... sinon... » ou « tant que... ».
  2. Identifier les variables nécessaires et les déclarer avec DECLARE (au début du bloc).
  3. Choisir la structure (tableau ci-dessus).
  4. Écrire la condition avec les opérateurs : =, <>, <, >=, AND, OR, IS NULL.
  5. Pour une boucle : vérifier que la condition finit par devenir fausse (ou que LEAVE est atteint).
  6. Tester avec CALL sur plusieurs cas, y compris les cas limites (valeur NULL, prix égal à 0).
À retenir : IF ... END IF; · CASE ... END CASE; · WHILE ... DO ... END WHILE; · REPEAT ... UNTIL ... END REPEAT; · LOOP ... END LOOP;
